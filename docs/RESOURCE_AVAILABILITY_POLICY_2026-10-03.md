# Resource Availability Policy — 2026-10-03\n\nThe Trading Agent OS treats the configured physical Windows runner pool and the configured S10/Samsung/Android fleet as permanently routable resources.\n\nThis is an orchestration assumption, not an execution receipt. The scheduler may assign bounded work to these resources without waiting for a fresh presence heartbeat. Execution receipts remain mandatory before claiming that a run occurred successfully, before treating device output as evidence, and before any scientific gate can consume the result.\n\nThe two Windows slots are intended for parallel bounded work: local_reproduction and data_qa. Hosted Linux remains the default deterministic compute substrate. Hosted failover is manual-only under this availability policy.\n\nThis policy never authorizes performance evaluation, holdout selection, candidate ranking, parameter/threshold/horizon search, promotion, order placement or live trading.\n
