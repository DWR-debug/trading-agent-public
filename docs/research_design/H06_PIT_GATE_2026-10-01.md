# H06 Sector-Neutral Residual Momentum — PIT Gate

Status: PIT-ONLY / NO PERFORMANCE AUTHORIZATION

The H06 repair uses a fixed 15-symbol, five-sector universe, a fixed 252-session
formation lookback and a fixed 21-session skip. Coverage is first established by
the canonical data layer on a 3,500-session common calendar. The PIT stage consumes
the coverage receipt and the exact snapshot created in the same workflow run.

The PIT harness checks every research decision point for three invariants:

1. Prefix truncation to the decision bar does not change the signal.
2. Mutating any strictly future bar does not change the signal.
3. Mutating the next actionable session does not change the signal formed at the decision bar.

No forward return, P&L, holdout metric, selection rule, parameter search or performance
authorization is computed or inferred by this stage.

Next gate: independent review of the immutable PIT receipt, followed by a separate
performance authorization only if the project's existing evidence gates permit it.
