# Q137/Q144 Micro PIT Readiness R1 — 2026-10-03

## Scope

This micro-wave takes two low-cost Q133–Q170 mechanisms whose source-feasibility and clock contracts are already explicit:

- Q137 — Disclosure-Processing Congestion: SEC filing acceptance timestamps and filing metadata.
- Q144 — Attention-Response Gap: SEC filing timestamps joined to a frozen Wikimedia Pageview page map.

It performs historical sample reconstruction only. No returns, performance metrics, holdout selection, ranking, asset selection, parameter search or trading are performed.

## Frozen sample boundary

- Universe: Q107 fixed universe, 8 symbols.
- Historical sample period: 2025-08-25 through 2025-09-24.
- Q137 identity: SEC CIK plus accession number.
- Q137 information clock: SEC acceptance timestamp.
- Q144 attention clock: Wikimedia daily pageview timestamp, UTC.
- Q144 entity mapping: `research/governance/q144_q107_wikipedia_page_map_2026_10_03.json`.

The sample period is a fixed structural reconstruction window, not a performance study window chosen from outcomes.

## Acceptance criteria

Q137 is structurally reconstructable when each issuer has at least one SEC submission in the sample period carrying filing date, acceptance datetime and accession number.

Q144 is structurally reconstructable when each frozen page returns a parseable historical pageview series with UTC timestamps and non-negative view counts, and the page identity returned by the API remains consistent with the frozen title.

A failure due HTTP/network access is classified as infrastructure/access evidence, not as historical absence.

## Future-data controls

- reverse input order must not change the parsed SEC event set;
- future-dated synthetic rows must not alter the fixed historical sample;
- SEC accession identifiers must be unique within the compiled sample;
- Wikimedia timestamps must be monotonic after sorting and unique;
- no query/search or outcome-driven page remapping is permitted after sample evaluation.

## Downstream boundary

This artifact cannot establish candidate-specific PIT validity for a complete validation universe. It is one bounded historical sample. Full candidate-specific PIT validation still requires immutable source preservation, coverage analysis, and independent reproduction.
