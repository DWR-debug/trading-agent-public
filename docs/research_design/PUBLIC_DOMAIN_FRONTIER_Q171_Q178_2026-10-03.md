# Public-Domain Frontier Q171–Q178 — 2026-10-03

This wave is deliberately broader than market, macro and filing datasets. It searches for information generated by public web archives, security-advisory systems, scientific repositories, transportation telemetry and physical-event networks.

## Q171–Q178 design principles

The common requirement is an information clock that is distinct from OHLCV and a reconstructable point-in-time boundary. Web crawls, advisories, nightly flight batches, scientific deposits, weather feeds and geophysical catalogs all have revision or dissemination semantics that must be modeled explicitly.

### Q171 — Common Crawl web-state transition

Common Crawl exposes CDXJ indexes over WARC captures and provides historical web snapshots. The candidate would use a frozen issuer URL set and measure mechanically defined content-state changes. Crawl lag and capture gaps are first-class feasibility risks.

### Q172 — GitHub Advisory / OSV vulnerability shock

GitHub's Advisory Database publishes security advisories and exposes a REST API; advisories use the OSV format. The candidate would translate newly public package advisories through a fixed package-to-issuer exposure graph. Publication, revision and withdrawal timestamps must remain separate.

### Q173 — OpenSky transport-network disruption

OpenSky exposes historical flight data, but its current terms state that commercial use requires consent and that its historical flight data are derived in a nightly batch for finished UTC days. Therefore Q173 is explicitly license-gated and cannot proceed to formal study until usage rights and reproducibility are established.

### Q174 — NOAA ERDDAP physical environment state

NOAA ERDDAP provides programmatic access to public scientific datasets in machine-readable formats. A candidate can combine a fixed geography/exposure graph with deterministic extreme-event states, but the underlying dataset's own update/revision behavior must be preserved.

### Q175 — Earthquake sequence state

The USGS catalog provides event-time, query and updated-after parameters. A sequence-state design can be more information-rich than a single-event trigger, but sequence construction must be frozen without using future returns.

### Q176 — Public research-output burst

Crossref and OpenAlex provide public scholarly metadata. The key issue is not article sentiment but reproducible event timing and a pre-frozen affiliation/domain map.

### Q177 — Space-weather transition

NOAA SWPC publishes alerts and related products with issue/correction/cancellation semantics. This allows a mechanically defined operational-state channel if the exposure taxonomy is frozen before outcomes are inspected.

### Q178 — Web/security collision state

The interesting property is two independent clocks rather than another feature of the same source. The state would encode whether a formal security advisory and a public web-state change occur in a deterministic temporal relationship, without ranking or tuning the collision window.

## Scientific boundary

Q171–Q178 remain design/discovery-only. No performance evaluation, holdout selection, asset selection, parameter search, threshold/horizon search, ranking, promotion or live execution is authorized.
