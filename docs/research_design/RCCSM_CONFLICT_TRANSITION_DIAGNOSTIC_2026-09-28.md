# RCCSM Conflict / Transition Diagnostic — 2026-09-28

Status: DIAGNOSTIC FEASIBILITY ONLY

The project now measures two independent structural quantities:

- mechanism disagreement from the frozen Q069 bank;
- state velocity, defined as the mean absolute movement of the four frozen RCCSM state descriptors between decision index t-21 and t.

The diagnostic does not assign a performance preference to either dimension. Its purpose is to separate:

- high disagreement with low state movement;
- high disagreement with high state movement;
- low disagreement with low state movement;
- low disagreement with high state movement.

This creates a fixed diagnostic map for later research without using future returns or holdout outcomes.

No performance evaluation or strategy authorization is part of this layer.
