# Trial 017b — Non-overlapping Political Event Window Control

Der Januar-Pilot 017 war ein reiner Pipeline-Control. Er enthielt 31 qualifizierte
Konflikttage und keinen Non-Conflict-Arm. Trial 017b adressiert diesen Befund.

Es gibt genau eine Beobachtung pro Ziel-Handelstag. Das Ereignisfenster liegt
zwischen dem letzten Handelsschluss und dem Zielhandelstag. Dadurch werden
Freitag-/Wochenendinformationen gemeinsam auf Montag abgebildet und dieselbe
Marktrendite nicht mehrfach verschiedenen Ereignistagen zugeordnet.

Der Filter bleibt unverändert: internationale Actor-Country-Codes, verschieden,
und mindestens drei meldende Artikel. Es findet keine Schwellenwert- oder
Parameteroptimierung statt.

Der Control bleibt Research-only. Ein positives Ergebnis verändert weder
Produktionsparameter noch Portfolioallokation.
