# AI Resource Efficiency — 2026-10-04

Use deterministic tooling for deterministic work. Reserve scarce model calls for bounded adversarial review, architecture review, and engineering diagnosis where a deterministic test can verify the result.

Automated AI work is event-driven rather than timer-driven. A new or materially changed research task/context may trigger one bounded review; unchanged context is not repeated solely because time elapsed.

Prefer one coherent batch review per research wave instead of one call per candidate. Invoke a second independent model only when the first review identifies a material ambiguity that merits independent attack.

The protected engineering reserve is kept for bounded engineering tasks. No paid fallback or overage is allowed.

AI output is worker material, not scientific evidence. It cannot select candidates from outcomes, alter gates, authorize performance, promote a strategy, or enable live execution.

Track calls per material state change, duplicate-context suppression, and the fraction of calls that produce a deterministic tested next action.
