# Sleeve Co-Movement Diagnostic — Public

Descriptive analysis of the joint behavior of the fixed Trend and Cross-Sectional
sleeves on the second independent validation artifact.

The analysis keeps the source data, signals, 50/50 weights, costs and split fixed.
It reports sleeve correlation, joint-negative days, opposite-sign days, covariance
share of portfolio variance and tail co-movement on the worst 5% portfolio days.

No parameter search, counterfactual, gate change, production mutation or orders.
Source: Public validation Run 35839443616 / Artifact 10740188093.
