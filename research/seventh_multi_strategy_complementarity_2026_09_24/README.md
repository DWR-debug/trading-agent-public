# Siebte Validierung – Multi-Strategie-Komplementarität

Ein präregistrierter Control auf einem vollständig symbol-disjunkten Datensatz.

Verglichen werden Trend-only, Cross-sectional-only und ein fester 50/50-Blend.

Es erfolgt keine Optimierung. Der Lauf dient der Prüfung, ob die beiden
Strategiefamilien auf neuer Datenbasis tatsächlich komplementäre Risiko- und
Stabilitätseigenschaften zeigen.
