# Ein-Sitzungs-CS-Cooldown – fünfte unabhängige Validierung

Diese Validierung prüft eine einzige, vorher festgelegte Architekturhypothese:
Nach einem vollständig beobachteten Cross-Sectional-Winner-Reversal wird das
50%-CS-Sleeve für genau die nächste Return-Periode auf Cash gesetzt.

Die vier bisherigen Validierungen bleiben unangetastet. Der neue Datensatz ist
vollständig symbol-disjunkt und umfasst 3.500 gemeinsame Candles mit einem
2.798/700 Research-/Holdout-Split.
